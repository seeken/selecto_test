# Selecto API Reference

## Host integration

- `Selecto.configure/2` and `Selecto.configure/3` build the configured query value.
- `SelectoViews.Explorer` provides the self-contained LiveComponent surface.
- `SelectoViews.State` is the canonical browser-state parser and serializer.
- `SelectoViews.Query` builds and executes governed detail, aggregate, and graph queries.
- `SelectoViews.Config` derives the finite UI catalog from the domain contract.
